## 📌 Огляд проєкту

Цей прототип є операційним хабом адміністратора салону краси (**Owned Salon Lviv**, вул. Кульпарківська, 96, ЖК Safe Town), розробленим у форматі **Telegram Mini App (TMA)** для оптимізації роботи з лідами Instagram Direct та інтеграції з системою автоматизації на **n8n (C1 Brain)**.

### ❓ Проблема поточного рішення (Telegram-картки в чаті):
1. **Хаос у груповому чаті:** Десятки повідомлень-карток щодня переповнюють чат адміністраторів. Важко відстежувати, які картки вже оброблені, які взяті в роботу, а які прострочені.
2. **Незручне редагування:** Для зміни часу чи майстра адміністраторки змушені писати текстові реплаї строгого формату (`25.09 14:00 Юля послуга: Стрижка`), що часто призводить до друкарських помилок і збоїв парсингу у `WF-10 Telegram Ops`.
3. **Обмеження інтерфейсу:** Inline-кнопки Telegram не дозволяють зручно переглядати розклад майстрів, обирати віконця календаря чи швидко копіювати структуровані нотатки для CRM (BookOn).
4. **Витрати n8n executions:** Багаторазове редагування картки в чаті для кожного кроку витрачає значну кількість викликів n8n.

## 🚀 Чому Telegram Mini App є кращим рішенням:

| Критерій | Telegram-картка (як зараз) | Telegram Mini App (прототип) |
|---|---|---|
| **Зручність персоналу** | Повідомлення губляться в чаті, треба пам'ятати команди | Організований беклог: *Потребують дії*, *Завдаток*, *Записи*, *Бот* |
| **Швидкість обробки** | ≈ 2.5–3 хвилини на ліда | **≈ 20–30 секунд** у 2 тапи |
| **Корекція даних** | Текстові реплаї, ризик regex-помилок у n8n | Інтерактивні форми, випадаючі списки, слоти, слайдери |
| **Синхронізація з CRM** | Ручне переписування даних | **1-клік копіювання** готових нотаток для BookOn |
| **Надійність для n8n** | Сотні рядків крихкого Regex/SQL парсингу | **Чистий типізований JSON Webhook** |
| **Контроль SLA** | Спам нагадуваннями від SLA Watch | Кольорові таймери в черзі (зелений / жовтий / червоний пульс) |

## 🧩 Архітектура інтеграції з n8n

```
[ Instagram Direct ] 
       │ (ManyChat Webhook)
       ▼
 [ WF-01 Inbound ] ──► [ WF-03 Triage ] ──► [ WF-05 Orchestrator / C1 Brain ]
                                                   │
                                                   ├─► [ Бот відповідає сам ] (WF-90 Send)
                                                   │
                                                   └─► [ Handoff / Потрібна людина ]
                                                             │
                                                             ├─► Сповіщення в Telegram:
                                                             │   "🔔 Запит від @client"
                                                             │   [ 📱 Обробити в Mini App ]
                                                             ▼
                                                    ┌────────────────────────┐
                                                    │   Telegram Mini App    │
                                                    │     (Salon Ops Hub)    │
                                                    └────────────────────────┘
                                                             │ (POST JSON Webhook)
                                                             ▼
                                                    [ WF-10 Ops Webhook ]
                                                             │
                                                             ├─► Запис у PostgreSQL / CRM
                                                             └─► [ WF-90 Send ] (підтвердження в Direct)
```

## 🛠 Технічний стек

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Dark Luxury Beauty Palette
- **Icons:** Lucide React + Native SVG
- **Telegram Native SDK:** WebApp API (Theme parameters, Haptic Feedback, Expand, Safe Area insets)
- **Deployment:** Vercel Production
